# Lumen Player

[![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-support-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/pusansen99)

An Android video player built on AndroidX Media3 (ExoPlayer). Cinematic-dark UI.

Paste a stream URL or open a local video file; it plays fullscreen. Also registers as a
video handler for file managers and the share sheet, and checks GitHub for its own updates.

## Requirements

- JDK 17 or 21 on `JAVA_HOME` (Gradle 9.1 does not run on JDK 26 yet).
- Android SDK with **platform android-36** and **build-tools 36.0.0**
  (`sdkmanager "platforms;android-36" "build-tools;36.0.0"`).
- `local.properties` with `sdk.dir=...` (machine-local; regenerated by Android Studio).

## Build & run

```sh
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew installDebug   # device/emulator connected
```

`minSdk` / `targetSdk` / `compileSdk` = 36 (Android 16) — deliberate, near-zero device reach today.

## Features

| Area | Notes |
|---|---|
| Engine | `ExoPlayer` + `DefaultRenderersFactory` (platform decoders, decoder fallback), audio focus, becoming-noisy |
| Formats | HLS / DASH / SmoothStreaming / progressive, `http` (cleartext) and `https` |
| Sources | typed URL · local file (SAF) · `ACTION_VIEW` / `ACTION_SEND` from other apps |
| UI | `PlayerSurface` + custom cinematic overlay: gradient scrims, accent scrubber with buffered track, tabular times; forced landscape while playing; immersive |
| Gestures | tap = controls · double-tap sides = ±10s · horizontal drag = scrub w/ preview · left/right edge vertical drag = brightness / volume (dead zone + haptic) |
| Tracks | audio / subtitle / video picker; subtitles start off; transparent caption style; adjustable subtitle size |
| Library | Home screen "Continue watching" + full history (Room); every play — URL, in-app file, or "Open with" from another app — is recorded and resumable |
| Resume | per-video position; "Resumed from …" chip; survives app-swipe (written on pause/stop) |
| Settings | TMDB API key field (metadata matching lands in a later update) |
| Errors | mapped `PlaybackException` card with Retry |
| Format badge | brief HDR / codec / resolution / audio chip at start |
| Updates | on launch, checks `github.com/<UPDATE_REPO>/releases/latest`; downloads + installs a newer APK |

## HDR / Dolby

HDR10 / HLG and single-layer Dolby Vision (profiles 5 / 8.1 / 9) play on a capable decoder + display.
HDR10+ falls back to the HDR10 base layer when unsupported. Dual-layer Dolby Vision (4 / 7) plays as
the HDR10/SDR base. Atmos / TrueHD are passthrough-only to a capable receiver, else decoded and
downmixed. This is the platform decoder path, not app code.

## Optional source-provided sidecars

Both are looked up next to an `http(s)` media URL, once per load. Absent → the feature simply
doesn't appear (one failed request, then nothing). Nothing is generated on-device.

### Thumbnail seek preview — WebVTT

Tried at `<base>.vtt`, `<base>-thumbnails.vtt`, `<base>.thumbnails.vtt`, `<url>.vtt`,
`<dir>/thumbnails.vtt`. Standard sprite-sheet form:

```
WEBVTT

00:00:00.000 --> 00:00:10.000
storyboard.jpg#xywh=0,0,180,101
```

Image refs are resolved against the VTT URL. One-image-per-cue (no `#xywh`) also works.

### Skip intro / recap / credits — JSON

Tried at `<base>.skip.json`, `<base>-skip.json`, `<base>.segments.json`, `<dir>/skip.json`:

```json
{ "segments": [
  { "type": "intro",   "start": 8000,    "end": 98000 },
  { "type": "recap",   "start": 0,       "end": 40000 },
  { "type": "credits", "start": 2580000 }
]}
```

`start`/`startMs` and `end`/`endMs` are both accepted (milliseconds). `type` is
`intro` / `recap` / `credits` (aliases: `opening`, `previously`, `outro`, `ending`).
`end` omitted → the segment runs to the end of the video. While playback is inside a
segment a "Skip …" pill shows bottom-right; tapping it seeks to `end`.

## Layout

```
app/src/main/java/com/lumen/player/
  MainActivity.kt                entry, edge-to-edge, incoming VIEW/SEND intents
  ui/theme/Theme.kt              cinematic-dark colour scheme
  player/
    PlayerScreen.kt              picker + player container; gestures, overlays, window effects
    PlayerControls.kt            cinematic control overlay + custom scrubber
    ManagedExoPlayer.kt          player construction, lifecycle, time formatting
    PlayerControls / PlayerExtras / GestureHud / FormatBadge / SubtitleOverlay
    PlayerErrorState.kt          error observation + overlay
    PlayerPrefs.kt               DataStore: last URL, resume positions
    ThumbnailPreview.kt          WebVTT thumbnails sidecar
    SkipSegments.kt              skip-segments JSON sidecar
  update/                        GitHub release check + APK download/install
```

Design canvas: see `design/` (the approved UI/UX `.dc.html` artboards).
