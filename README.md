# Lumen Player

An Android video player built on AndroidX Media3 (ExoPlayer). Cinematic-dark UI.

**Status: Phase 1 — walking skeleton.** Paste a stream URL or open a local video file, and it plays
fullscreen with minimal controls (play/pause, scrub, ±10s). Everything else from the design canvas
(library scan + TMDB metadata enrichment, background playback, PiP, custom cinematic chrome) is later
phases.

## Requirements

- JDK 17 or 21 on `JAVA_HOME` (Gradle 9.1 does not run on JDK 26 yet).
- Android SDK with **platform android-36** and **build-tools 36.0.0**.
  Install if missing: `sdkmanager "platforms;android-36" "build-tools;36.0.0"`.
- `local.properties` with `sdk.dir=...` (created for this machine; regenerated by Android Studio).

## Build & run

```sh
# device or emulator connected
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew installDebug
```

Or open the project root in Android Studio and Run.

## Configuration

- `minSdk` / `targetSdk` = 36 (Android 16). Deliberate — near-zero device reach today.
- `compileSdk` = 36.

## What Phase 1 covers

| Area | Included |
|---|---|
| Playback engine | `ExoPlayer` via `DefaultRenderersFactory` (platform decoders, decoder fallback), audio focus, becoming-noisy handling |
| Formats | HLS, DASH, SmoothStreaming, progressive MP4/WebM (auto-detected by `DefaultMediaSourceFactory`) |
| Sources | Stream URL (typed) · local file (SAF `OpenDocument`) |
| UI | `PlayerSurface` (media3-ui-compose) + custom overlay; 3s auto-hide; tap to toggle |
| Lifecycle | pause on `ON_STOP`, release on dispose, keep-screen-on while playing |

## HDR / Dolby notes

HDR10 / HLG and single-layer Dolby Vision (profiles 5 / 8.1 / 9) play where the device has a capable
decoder and display. HDR10+ falls back to the HDR10 base layer when unsupported. Dual-layer Dolby
Vision (profiles 4 / 7) is not supported on Android and plays as the HDR10/SDR base. Dolby Atmos /
TrueHD are passthrough-only to a capable receiver; on built-in speakers they are decoded and
downmixed. None of this is app code — it is the platform decoder path.

## Layout

```
app/src/main/java/com/lumen/player/
  MainActivity.kt              entry point, edge-to-edge, LumenTheme
  ui/theme/Theme.kt            cinematic-dark color scheme
  player/
    PlayerScreen.kt            source picker + player container + auto-hide/keep-screen-on
    PlayerControls.kt          overlay: back, scrubber + times, transport row, buffering spinner

```
