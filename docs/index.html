03:40 — Tracks & subtitles

Pick the audio, subtitle, and quality you want.

Subtitles start off and render with a transparent background and adjustable size — no opaque black box over the picture. Resume where you left off; the last URL you played is waiting in the box.

06:00 — Updates

It updates itself.

On launch Lumen checks GitHub for a newer release. If there is one, it shows the notes, downloads the APK, and hands it to the installer. No store, no account, no background service.

Around 4 MB installed — R8-shrunk, one ABI, no debug build. arm64, Android 16+.

Sideload the APK. You’ll need “install unknown apps” for your browser or file manager the first time.
